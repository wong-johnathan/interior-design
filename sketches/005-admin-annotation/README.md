## Wireframe: Admin Room Annotation

### Design stance
Tool-like, functional. Maximizes canvas space for floor plan drawing.

### Key choices
- Layout: Full canvas (70%) + properties panel (30%)
- Color: Dark theme (admin tool, not user-facing), amber admin badge
- Interaction: Toolbar at bottom (Draw, Select, Door, Window, Delete), zoom controls
- Properties: Room type, label, dimensions, materials, doors, windows sections

### What it covers
- Floor plan canvas with room polygons overlaid
- Color-coded room types (teal=living, blue=MBR, emerald=kitchen, amber=shelter)
- Door/window indicators on walls
- Full properties panel with all RoomConfig fields
- Toolbar with drawing tools
- Room dimension auto-calculation display
