## Variant: Centered Dark Landing

### Design stance
Dark, sleek, app-like. Slate gradient bg with teal accent. Feels like a premium tool.

### Key choices
- Layout: Centered single column, narrow width — reading-focused
- Typography: Large bold headline, softer body text
- Color: Dark slate bg, teal-300 accent, subtle border cards
- Interaction: Rounded buttons, hover effects, step indicator

### Trade-offs
- Strong at: Impactful, memorable, modern app feel
- Weak at: Less info above fold (need to scroll for features)

### Best for
Mobile-first users, younger audience, tech-forward positioning
