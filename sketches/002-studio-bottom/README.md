## Variant: Bottom Panel Studio

### Design stance
Mobile-friendly, content-first. Maximizes 3D viewport space.

### Key choices
- Layout: Full-width viewport (70%), bottom panel (30%) with tabs
- Color: Dark theme, match studio variant
- Interaction: Tab bar for switching between Chat / Brief / Furniture
- Breadcrumb: Same top nav, active stage indicator

### Trade-offs
- Strong at: More 3D space, works on smaller screens
- Weak at: Less simultaneous info, need to tap tabs to switch

### Best for
Tablet users, quick design sessions, users focused on the 3D view
